오늘 핵심: 국내에서는 기업 SI 개발공정의 에이전틱 AI 전환과 엔비디아-한국 피지컬 AI 접점이 두드러졌다. 해외에서는 Google의 Agentic RAG, OpenAI의 장기 메모리, GitHub Copilot의 대형 컨텍스트와 사용량 기반 비용 논쟁, NVIDIA Cosmos 3, xAI 이미지-투-비디오 API가 실무 흐름을 만들고 있다.

국내뉴스 우선 정리

1. LG CNS, 대형 SI 개발 공정을 에이전틱 AI 중심으로 재편

ZDNet Korea는 LG CNS가 대규모 IT 시스템 구축·운영 전 과정을 에이전틱 AI 기반으로 수행하는 개발 플랫폼 DevOn Agentic AIND를 출시했다고 보도했다.

  • 요약: 단순 코드 생성 도구가 아니라 요구사항 분석, 설계, 개발, 테스트, 운영까지 기업 SI 전체 공정에 AI 에이전트를 넣는 방향이다.
  • 핵심 포인트: 금융·제조·공공처럼 복잡하고 문서가 많은 프로젝트에서 AI가 산출물 작성, 코드 변경, 검증 흐름을 보조하는 구조가 중요해진다.
  • 왜 중요한가: 국내 AI 도입 경쟁이 챗봇과 개인 개발자 생산성에서 기업 개발 방법론 자체를 바꾸는 단계로 넘어가고 있음을 보여준다.

2. 젠슨 황, 국내 AI·로봇 스타트업과 비공개 간담회 예정

ZDNet Korea는 젠슨 황 엔비디아 CEO가 6월 8일 저녁 서울에서 국내 AI·로봇 스타트업 경영진과 비공개 간담회를 갖는다고 보도했다.

  • 요약: 업스테이지, 트웰브랩스, 모레, 로보티즈 등 국내 AI·로봇 기업과 엔비디아의 피지컬 AI 생태계 접점이 부각됐다.
  • 핵심 포인트: 한국 AI 이슈가 LLM 앱과 서비스뿐 아니라 로봇, 엣지 AI 최적화, 제조·물류 현장 데이터 경쟁으로 넓어지고 있다.
  • 왜 중요한가: 피지컬 AI는 실제 환경 데이터, 로봇 제어, 시뮬레이션, 반도체 인프라가 함께 맞물려야 하므로 국내 산업과 연결성이 크다.

해외 검증 뉴스

1. Google, Gemini Enterprise Agent Platform 기반 Agentic RAG 공개

Google Research는 2026년 6월 5일 Google Research와 Google Cloud 협업으로 Gemini Enterprise Agent Platform-hosted Cross-Corpus Retrieval powered by Agentic RAG를 소개했다.

  • 요약: 표준 RAG가 한 번 검색하고 답하는 구조라면, Agentic RAG는 복잡한 질문을 하위 질문으로 나누고 문맥이 충분한지 판단해 다시 검색한다.
  • 핵심 포인트: Query Rewriter와 Sufficient Context Agent를 통해 검색 누락과 불충분한 근거를 줄이는 다중 에이전트 워크플로가 핵심이다.
  • 왜 중요한가: 기업용 RAG 경쟁이 벡터 검색 정확도만이 아니라 검색-판단-재검색-근거 확인을 설계하는 에이전트 워크플로 경쟁으로 이동하고 있다.

2. OpenAI, ChatGPT 메모리의 dreaming 기반 합성 구조 강화

OpenAI는 2026년 6월 4일 ChatGPT 메모리를 더 최신성 있고 연속성 있게 합성하는 dreaming 기반 구조를 발표했다. 관련 제어 설명은 OpenAI Help Center Memory FAQ에도 반영되어 있다.

  • 요약: 오래된 메모리, 모순되는 선호, 장기 프로젝트 맥락 누락을 줄이기 위한 더 확장성 있는 메모리 합성 시스템이다.
  • 핵심 포인트: 미국 Plus·Pro 사용자부터 시작해 추후 다른 국가와 Free·Go 사용자로 확대될 예정이다.
  • 왜 중요한가: AI 개인화가 단순히 정보를 저장하는 기능에서, 시간에 따라 갱신되고 사용자가 검토·수정할 수 있는 장기 맥락 관리 기능으로 이동한다.

3. GitHub Copilot, 대형 컨텍스트와 추론 수준 조절 제공

GitHub Changelog는 2026년 6월 4일 Copilot이 VS Code, Copilot CLI, GitHub Copilot 앱에서 100만 토큰 컨텍스트 창과 configurable reasoning levels를 지원한다고 밝혔다.

  • 요약: 대형 코드베이스와 복잡한 설계·디버깅 작업을 더 긴 컨텍스트와 깊은 추론으로 처리할 수 있게 한다.
  • 핵심 포인트: GitHub는 큰 컨텍스트나 높은 추론 수준을 선택하면 AI Credit 소비가 증가한다고 명시했다.
  • 왜 중요한가: 개발자는 이제 더 강한 에이전트 기능뿐 아니라 컨텍스트 크기, 추론 단계, 비용 한도를 함께 설계해야 한다.

4. 개발자 커뮤니티, Copilot 사용량 기반 과금에 강한 반응

Tom's Hardware는 Copilot 사용량 기반 과금 전환 이후 일부 고객이 큰 비용 증가를 보고했다고 보도했다. GitHub Community 토론에서도 AI Credit 소모량에 대한 우려가 이어지고 있다.

  • 요약: 대형 컨텍스트, 고급 모델, 에이전트 작업이 가능해질수록 실제 토큰·크레딧 비용이 사용자 불만의 핵심이 되고 있다.
  • 핵심 포인트: 커뮤니티 반응은 기능 자체보다 예측 가능한 비용, 제한 안내, 사용량 가시성에 집중되어 있다.
  • 왜 중요한가: AI 코딩 도구 시장은 성능 경쟁과 동시에 비용 투명성·거버넌스 경쟁으로 바뀌고 있다.

5. NVIDIA Cosmos 3, 피지컬 AI용 오픈 월드 파운데이션 모델

NVIDIA 공식 보도자료와 NVIDIA Blog에 따르면 Cosmos 3는 시각 추론, 세계 생성, 행동 예측을 결합한 피지컬 AI 기반 모델이다.

  • 요약: 로봇, 자율주행, 비전 AI가 실제 세계에서 행동하기 전 시뮬레이션하고 학습할 수 있도록 돕는 모델 제품군이다.
  • 핵심 포인트: Cosmos 3 Super와 Nano는 사용 가능하고 Edge는 실시간 엣지 추론용으로 예고됐다.
  • 왜 중요한가: 국내 피지컬 AI 흐름과 연결해 보면, 현장 데이터·시뮬레이션·로봇 정책 학습 인프라가 AI 경쟁의 핵심으로 떠오르고 있다.

6. xAI, Grok Imagine 1.5 이미지-투-비디오 API 프리뷰

xAI는 2026년 6월 3일 grok-imagine-video-1.5-preview를 API 프리뷰로 공개했다.

  • 요약: 시작 이미지와 프롬프트를 넣으면 카메라 움직임, 분위기, 물리감이 반영된 최대 720p 영상 클립을 생성한다.
  • 핵심 포인트: 원본 이미지의 디테일과 조명을 유지하면서 샷 단위 영상을 이어 붙이는 워크플로를 제시했다.
  • 왜 중요한가: 이미지 생성 모델 경쟁이 영상 제작 파이프라인, API, 시퀀스 일관성 경쟁으로 빠르게 확장되고 있다.
